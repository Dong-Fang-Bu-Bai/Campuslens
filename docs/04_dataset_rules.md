# 数据集规范

## 目录与编号

地标样本放置在 `datasets/landmarks/`，每个地标使用固定目录。目录名以地标编号开头，完整映射见[样本目录](../datasets/landmarks/sample_inventory.md)。

样本原图、模型权重和索引在本地单独准备，不纳入 Git。地图位置、地标名称和样本目录使用一致的 L01–L10 编号。

## 图片命名

```text
<landmarkCode>_<angle>_<light>_<index>.jpg

L01_front_day_001.jpg
L01_side_cloudy_002.jpg
L04_far_day_001.jpg
```

| 字段 | 含义 | 示例 |
| --- | --- | --- |
| landmarkCode | 地标编号 | L01 |
| angle | 拍摄视角 | front、side、far、near、entrance |
| light | 光照条件 | day、cloudy、evening、backlight |
| index | 同类样本序号 | 001、002 |

文件名统一使用地标编号、拍摄条件和序号。

## 样本质量

- 每个地标建议准备至少 20 张有效图片，覆盖正面、侧面、远景、近景和典型入口。
- 补充不同光照、距离与遮挡条件，减少单一拍摄场景的偏差。
- 去除标签不确定、严重模糊、主体过小及重复度高的图片。
- 为每个地标选择代表图，并同步数据库封面字段。
- 增删样本后重新构建索引，检查每类有效样本数和统计参数。
- 评测图片与索引样本分离，避免近重复图片同时进入两者。

## 地标元数据

地标至少包含编号、名称、类型、位置描述、简介、代表图和地图坐标。地图采用百分比坐标，左上角为原点，X / Y 范围为 0–100。

新增地标时同步更新分类目录与数据库迁移。修改字段结构时同步更新[数据字典](03_data_dictionary.md)及[接口契约](02_api_contract.md)。

## 校正样本

用户反馈经管理员采纳后，图片进入对应地标的待发布目录。待发布样本通过索引重建和原子发布进入检索，不直接替换活动索引。详见[索引发布流程](architecture.md#反馈与索引发布)。
