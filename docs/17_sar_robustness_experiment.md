# CampusLens SAR受控扰动对照实验

## 1. 实验定位

本实验基于CampusLens当前212张地标建库图片构造受控图像退化，比较普通检索与SAR增强检索在相同输入条件下的相对变化。实验用于分析噪声、亮度降低和模糊对Top-K检索、候选分离度、预测稳定性与响应开销的影响。

本实验不是独立现场测试集，不用于宣称系统的真实泛化准确率。原始图片参与了FAISS地标统计和索引构建，因此实验结果只能解释为建库样本经过受控扰动后的压力测试结果。

实验设计参考SAR论文对测试时分布偏移、小批量输入和在线顺序变化的关注，但不直接使用论文的ImageNet-C数据或实验数字：

> Shuaicheng Niu et al., *Towards Stable Test-Time Adaptation in Dynamic Wild World*, ICLR 2023, arXiv:2302.12400.

## 2. 数据与扰动

- 从10个地标中各选择5张基础图片，共50张。
- 优先覆盖`front`、`back`、`entrance`、`far`、`side`、`near`等不同视角；视角不足时用dHash差异补足。
- 固定抽样种子为`42`，清单记录源路径、SHA-256、dHash和选择理由。
- 每张基础图片保留1个原图条件，并生成三类扰动的level 1至5：
  - 高斯噪声标准差：5、10、15、25、35；
  - 亮度系数：0.90、0.78、0.65、0.52、0.40；
  - 高斯模糊半径：0.5、1.0、1.5、2.2、3.0。
- 总条件数为`50 × (1 + 3 × 5) = 800`。
- 扰动默认在内存中确定性生成，不保存800张中间图；高斯噪声种子由基础图片、扰动类型和强度共同派生。

## 3. 对照运行

- Baseline使用不可变基准模型按固定清单运行800次。
- SAR按固定种子`42`、`2026`、`704`形成三种输入顺序，每轮运行800次。
- 每轮SAR使用独立临时检查点和事件日志，并从同一初始状态开始。
- 测试期间模型版本或索引版本发生变化时立即终止，禁止混合不同版本结果。
- 每条记录保存真实地标、Top-5快照、真实排名、经验匹配分、延迟、`sarApplied`和版本信息。

完整实验共生成`800 + 3 × 800 = 3200`条请求记录。

## 4. 指标与统计

| 指标 | 解释 |
| --- | --- |
| Top-1 / Top-5 | 真实地标是否位于第一名或前五名 |
| MRR | 真实地标排名倒数均值，未进入Top-5记0 |
| 候选分离度D | `Top-1经验匹配分 - Top-2经验匹配分`，不解释为概率 |
| Top-1预测保持率 | 当前Top-1是否与Baseline原图Top-1一致 |
| Top-5 Jaccard | 当前Top-5集合与Baseline原图Top-5集合的交并比 |
| P50 / P95延迟 | 典型请求耗时与尾部请求耗时 |
| SAR应用率 | SAR请求中实际通过门控并更新的比例 |

扰动条件来自同一批50张基础图片，不能把800个衍生输入当作800个独立样本。实验以`baseImageId`为聚类单位进行2000次配对Bootstrap，并同时保留SAR三种输入顺序的轮次差异。

## 5. 输出与复现

运行：

```powershell
cd algorithm
python -m pip install -r requirements-evaluation.txt
python evaluate_sar_robustness.py all
```

默认结果位于：

```text
软件开发实训文档汇总/图片/测试/SAR鲁棒性实测_<时间戳>/
```

目录包含基础图片清单、扰动清单、3200条逐请求CSV/JSON、汇总JSON、运行诊断、PNG/SVG图表、基础图片联系表、扰动预览和`preview.html`。

中断后可在同一输出目录重新执行`run`。已完整结束的运行会复用；未完成的SAR轮次会从相同初始状态重新开始，避免恢复到不可追溯的中间状态。

## 6. 2026-07-04实测结果

本次正式运行使用`base-0b8b82f85de9`基准模型、`index-015c7321-8179-44e3-9e81-c937cbad92e3`活动索引和NVIDIA GeForce RTX 4060 Laptop GPU。模型与索引版本在3200条请求中保持一致；三轮SAR均从`sar-g1-u0`开始，各自在隔离的临时状态中结束于`sar-g1-u800`，未修改正式SAR状态。

| 指标 | Baseline | SAR（3轮汇总） | 解释 |
| --- | ---: | ---: | --- |
| 请求数 | 800 | 2400 | 800个条件，SAR使用3种固定顺序 |
| Top-1 | 100.00% | 100.00% | 本轮既定扰动范围内无差异 |
| Top-5 | 100.00% | 100.00% | 本轮既定扰动范围内无差异 |
| MRR | 1.0000 | 1.0000 | 真实地标均排在首位 |
| 平均候选分离度D | 0.6115 | 0.6988 | SAR的Top-1与Top-2经验分差更大 |
| Top-1预测保持率 | 100.00% | 100.00% | 相对原图预测均保持一致 |
| 平均Top-5 Jaccard | 93.79% | 87.32% | SAR改变次级候选集合的幅度更大 |
| P50延迟 | 104.57 ms | 731.78 ms | SAR增加约627 ms |
| P95延迟 | 117.89 ms | 827.50 ms | SAR增加约710 ms |
| SAR应用率 | — | 100.00% | 2400个SAR请求均通过门控并更新 |

实测结论是：在本轮预先固定的噪声、低亮度和模糊强度范围内，两种模式的Top-1、Top-5和MRR均达到饱和，因而不能据此宣称SAR提高了命中准确率。SAR使平均候选分离度从0.6115提高到0.6988，但同时使Top-5集合重合度下降，并带来显著延迟和显存开销。工程上仍应保留普通/SAR双轨与回退机制，不应默认对全部请求启用SAR。

## 7. 结果使用规则

结果数字和结论必须来自同一份`summary.json`。如果SAR指标下降，应如实写出下降范围及延迟代价，不得筛选有利扰动或预先写定“SAR有效”。

最终报告和PPT应使用“受控扰动压力测试”“相对鲁棒性变化”等表述，不使用“独立测试集准确率”“真实泛化准确率”等表述。

本次结果已由同一份`summary.json`生成CSV、JSON、PNG、SVG和HTML预览。后续若更换模型、索引、扰动参数或基础样本，必须新建结果目录并重新生成文档数字，不能与本轮结果混用。
