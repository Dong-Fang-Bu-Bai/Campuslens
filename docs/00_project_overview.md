# 项目概览

CampusLens（校园慧眼）面向校园地标识别与导览。用户上传照片，系统检索候选地标，并将识别结果与介绍、地图位置及反馈入口关联。

## 功能范围

- 图片上传、异步检索、Top-5 候选展示与低匹配等级提示。
- 地标详情、代表图及校园平面图标注。
- 登录注册、账号资料、头像、密码找回和检索历史。
- 识别反馈、管理员审核、校正样本与索引重建。
- 关联检索记录的校园打卡、留言、多级回复和点赞。
- 基准检索与可选 SAR 模式，模型与索引版本管理。

地图采用静态平面图，不提供实时路线规划或室内导航。图像特征由预训练 DINOv2 提取。

## 使用流程

1. 选择或拍摄校园照片，提交检索。
2. 根据任务状态查看 Top-5 候选及匹配等级。
3. 打开地标详情或定位到平面图。
4. 对结果提交确认或纠错；可从候选地标发布打卡。
5. 管理员审核反馈，将有效校正样本纳入索引发布流程。

上传照片默认不在社区公开；只有发布者开启照片展示后，打卡内容才包含来源图片。打卡地标必须来自本人检索记录的候选集合。
